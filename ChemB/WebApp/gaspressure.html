2D気体分子運動論：重い分子 vs 軽い分子

同じ絶対温度（＝平均運動エネルギーが等しい）における分子の質量と移動速度・壁衝突頻度のリアルタイム比較

重い分子 (例: アルゴン/酸素)
分子質量 $m$: 16 (相対値)
平均速度 $\sqrt{\overline{v^2}}$: 0
平均運動エネルギー $\bar{E}$: 0
衝突頻度 (1秒間): 0 回
軽い分子 (例: ヘリウム/水素)
分子質量 $m$: 1 (相対値)
平均速度 $\sqrt{\overline{v^2}}$: 0
平均運動エネルギー $\bar{E}$: 0
衝突頻度 (1秒間): 0 回
物理のポイント：
平均運動エネルギーは $\bar{E} = \frac{1}{2}m\overline{v^2} = \frac{3}{2}k_\text{B}T$ と表され、分子の種類（質量 $m$）によらず絶対温度 $T$ のみに依存します。
したがって、同じ温度であれば「重い分子（$m$が大）」は遅く、「軽い分子（$m$が小）」は速く飛び交い、容器壁への衝突頻度が高くなります。
